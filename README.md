# PREND (프렌드)

**사고·고장·갑자기 아픈 순간에 당황한 운전자 곁에서 지금 할 일을 한 걸음씩 말해 주고, 사고로 멈춰 서면 부르기 전에 차가 먼저 묻는 Pleos Connect 앱입니다.**

이름은 기어 P·R·N·D 사이에 급할 때의 E(Emergency)를 넣은 것이고, 읽으면 프렌드입니다. 앱 화면에서 E는 '긴급'으로 씁니다. 평소에는 차 신호로 운전자가 바쁜 때를 알아 말을 아끼고(말할 때 고르기), 급할 때는 앞장섭니다. 먼저 챙기는 사람은 첫 차를 모는 초보와 아이를 태우는 부모이고, 급한 순간에는 누구나 당황하니 모든 운전자에게 쓰입니다.

## 실행 방법 (에뮬레이터에서 급할 때 장면 다시 해 보기)

1. Pleos Connect 에뮬레이터(Android Automotive 14, x86_64)를 켜고 `adb install -r --user 10 apk/<APK 파일>`로 설치합니다. 출시 APK 하나에 실차(arm64-v8a)와 에뮬레이터(x86_64)가 함께 들어 있습니다(아래 'APK 위치').
2. 런처에서 PREND를 엽니다. 처음 열면 까닭 판 한 장 뒤에 차 속도와 알림 허락 창이 뜹니다([허락하기]). 거절하면 세워 둔 첫 화면에 한 줄과 [허락하기]가 남습니다. 마이크는 대화 중엔 소리 낮추기를 켤 때만 묻습니다. 시동과 함께 깨어나는 서비스가 바로 시작됩니다.
   처음 세워 둔 채 문이 모두 닫히면 가족 정보 물음과 위치를 어디에 쓰는지 알리는 카드가 한 장씩 뜹니다. 곁들임 물음(한 시간 운전·대리 운행·대화 중엔 소리 낮추기·오래 막힐 때·밥집·카페)은 꺼져 있고 [설정]의 '먼저 물어볼 것'에서 켭니다.
3. Virtual Console(`adb forward tcp:8088 tcp:8088` 뒤 http://127.0.0.1:8088)로 차를 움직입니다.
   - **혹시 사고(콘솔 신호만):** 기어 D → 가속해 시속 60 → 브레이크를 3초 꾹(1초에 시속 15km 넘게 줄어야 함) → 5초 안에 멈춤 → 1분 안에 기어 P → 운전석 문(Front left) Open → "혹시 사고 나셨어요?"
   - **급할 때 화면:** 첫 화면의 큰 단추 [긴급](달리는 동안은 가운데 [긴급] 줄) → [사고가 났어요] / [갑자기 아파요] / [고장 났어요] / [연기가 나요]
   - **대피 뒤:** 대피 문장 뒤 문(어느 자리든)을 Open하면 목소리가 멈추고, 자리에 앉은 채 Close하면 이어 갑니다
   - **화장실 찾기:** [프렌드]를 누르고 "애가 쉬 마렵대"처럼 말하면 앞쪽에서 들르기 쉬운 휴게소·졸음쉼터·주유소 한 곳을 카드로 묻고, [경유지로]를 누르면 내비에 넣습니다
4. 에뮬레이터에 없는 값(에어백 전개, 고속도로 위 위치, 블루링크 통화)은 시연 패널에서 넣습니다: PREND 위 막대의 이름(P R E N D)을 3초 안에 다섯 번 누르면 열립니다(PT 빌드만). ① 장면 준비, ② 고속도로, ③ 블루링크 통화 + 에어백. ②·③도 ①부터 하므로 단추 하나로 장면이 시작되고, 콘솔의 문이 열려 있으면 패널 맨 위에 크게 알립니다(문을 닫은 뒤 시작).

## 테스트 환경과 필요한 설정

- Pleos Connect 에뮬레이터(Android Automotive 14), Virtual Console, Windows 11. 실차에서는 시험하지 않았습니다(공모전 검증은 에뮬레이터).
- 인터넷: 실시간 병원 찾기·생성형 AI 대역(규칙에 없는 말 이해)·도로 등급은 중계 서버를 거칩니다. 인터넷이 없어도 급할 때 안내와 앱 안 병원 목록은 그대로 됩니다.
- 권한은 매니페스트의 Pleos SDK 권한 선언으로 충분합니다(공모전 개발 단계는 승인 불필요).

## APK 위치

- `apk/김민규_PREND_release.apk`: 출시판. 실차(arm64-v8a)와 에뮬레이터(x86_64)를 함께 담아 어느 쪽에서도 설치해 돌릴 수 있습니다. 출시 키로 서명했습니다.
- `apk/김민규_PREND_pt.apk`: 시연 패널과 PT 장면 단추(에어백·블루링크 통화·고속도로 위치 같은 시험 값)가 든 PT 빌드(`gradlew assemblePt`). 출시판과 같은 키로 서명해 서로 바꿔 깔 수 있습니다.

## 저장소 구성

| 폴더 | 들어 있는 것 |
|---|---|
| `app/` | 앱 소스(Kotlin, Jetpack Compose)와 앱에 넣은 자료(목소리, 시연 음악, 졸음쉼터·주유소·병원 목록, 응급처치 그림) |
| `apk/` | 설치 파일 두 가지(위 'APK 위치') |
| `relay/` | 중계 서버(Cloudflare Workers) 소스. 키는 들어 있지 않고 서버의 비밀값에만 있습니다 |
| `tools/` | Virtual Console로 가상 차를 모는 도구(`vcride.js`, `ptkeys.js`: `tools`에서 `npm install` 뒤 Chrome으로 콘솔 화면을 누릅니다. adb 경로는 `ADB` 환경 변수), 시연 음악 합성(`make_music.js`), 앱 안 목록을 공공데이터로 만드는 도구(`build_gas.js`, `build_rest.js`, `build_reststops.js`, `collect_hospitals.js`) |

## 기능

- **P·R 세워 둔 동안**: 주차 자리 한 번, 주차하는 동안 조용히(차의 주차 경고음이 들리게), 멈춰 서서 핸들을 돌릴 때 바퀴 방향, 출발 전 '도착하면 어두워요'(해 지기 전에), 운전 도움이면 골목 안 목적지에 큰길가 주차장 한 번, 차 정비(정비 때·직접 하기·가까운 블루핸즈·정비소에서의 권리, 정비소에 가면 오늘 날짜로 [기록하기]), 출발 전 목적지 비·눈 예보, 쪽잠과 깨우기, 밥집·카페, 설정
- **E 급할 때**: 사고 안내(고속도로·일반 도로·가벼운 사고), 고장 안내(고속도로·일반 도로, 고속도로 무료 긴급견인 1588-2504, 부르지 않은 견인차), 연기·타는 냄새, 고속도로 위에서 P면 대피 카드, 갑자기 아플 때(운전자가 아프면 병원으로 몰고 가지 말고 세운 뒤 119, 같이 탄 사람이면 병원 경유지), 응급처치 카드, 119 전화
- **N·D 달리는 중**: 말해도 되는 때 고르기(깜빡이·후진·급제동·회전 직전·길을 다시 찾는 중엔 삼킴), 카드는 설 때만, 운전 도움 한마디(비 오는 날은 그 길 제한속도로 '시속 60 아래'처럼, 회전교차로, 우회전), 운전 도움을 끈 사람에게는 젖은 길·우회전을 소리 없는 카드로 한 번, 김서림이면 바깥 공기로, 두 시간 쉼터 권하기(졸음쉼터와 휴게소, 주유소 있음 표시), "화장실 급해"·"애가 쉬 마렵대"면 앞쪽 휴게소·졸음쉼터(수유실 표시)나 오른쪽 앞 주유소를 카드로 권하고 "응"이면 경유지로, 창문·이야기에 비켜 서는 음악. PREND가 먼저 꺼내는 말·카드는 한 운행에 여섯 번, 동승자가 있으면 대리 운행·지난 사고·정체·주차 자리처럼 민망할 수 있는 말은 소리 없는 카드로(쉼터·급할 때는 목소리), 급한 말만 하기는 이번 운행만이나 늘까지
- **말하기·듣기**: "뭐라고?"면 방금 한 말을 천천히 다시, 자주 되물으면 늘 천천히, 대답이 늦으면 듣는 시간을 늘림(나이를 묻지 않고 쓰는 모습으로 맞춤), 대답을 못 알아들으면 한 번만 다시 묻고 그다음엔 카드 버튼만(가족 정보 물음·동승자가 있을 때는 바로 카드만), 사투리 대답(하모·그려·아이다·뭐라카노)도 알아들음. 세 가지 모두 [설정]에서 켜고 끔

시동과 함께 깨어나 운행 내내 켜져 있는 서비스(RideService)가 차 신호를 받아 지금이 어느 순간인지 고르고, 소리·빛·바람·미리 만든 목소리·경유지로 챙깁니다.

## 빌드

필요한 것: JDK 17, Android SDK 35(`local.properties`의 `sdk.dir`이나 `ANDROID_HOME`). Gradle 8.13은 들어 있는 `gradlew`가 받습니다(AGP 8.8.2, Kotlin 2.2.21). Pleos Playground SDK는 `settings.gradle.kts`의 Pleos Maven 저장소에서 받습니다.

```
gradlew assembleDebug     # 시험용: 실차(arm64-v8a)와 에뮬레이터(x86_64), 시연 패널·시험 명령
gradlew assembleRelease   # 제출용: 실차(arm64-v8a)와 에뮬레이터(x86_64), R8로 줄임, 시연 패널 없음
gradlew assemblePt        # PT·시연 영상용: 출시판과 같은 최적화 + 에뮬레이터(x86_64) + 시연 패널·시험 명령
```

macOS·Linux에서는 `./gradlew`로 부릅니다.

- 출시 APK는 실차와 에뮬레이터 두 가지 기기용 파일을 함께 담습니다(심사는 에뮬레이터에서 하므로, 11/07).
- 출시 키는 저장소 바깥(`../.secrets/keystore.properties`와 키 파일)에 두고, 없으면 디버그 키로 서명합니다. PT 판도 같은 출시 키로 서명합니다. 디버그 판은 디버그 키라 출시·PT 판과 바꿔 깔 때는 먼저 `adb uninstall app.prend`로 지웁니다.
- minSdk 28, targetSdk 35. 시험한 기기는 Pleos Connect 에뮬레이터(Android Automotive 14)입니다.

### 키는 저장소에 없습니다

앱이 쓰는 비밀값은 중계 서버를 부르는 앱 토큰 하나입니다. `app/build.gradle.kts`가 빌드할 때 저장소 바깥의 `../.secrets/relay-token.txt`를 읽어 `BuildConfig.RELAY_TOKEN`에 넣고, 파일이 없으면 빈 값으로 빌드합니다. 그때는 중계 서버를 거치는 기능(밥집·카페, 실시간 병원 찾기, 생성형 AI 대역)만 꺼지고 나머지는 그대로 돕니다. 인터넷이 없으면 병원은 앱에 넣어 둔 목록에서 고릅니다.

이 토큰은 공모전 시연용입니다. 중계 서버는 보낸 곳(IP)마다 1분에 40번, 생성형 AI는 1분에 10번까지만 받고, 생성형 AI는 모든 곳을 합쳐 하루 500번에서 멈춥니다(`relay/wrangler.jsonc`, `relay/src/worker.js`). 멈춘 동안 앱은 "서버가 바빠요"라고 알리고, 정해 둔 말과 급할 때 안내는 그대로 됩니다. 공모전이 끝나면 토큰을 바꿔 지난 APK가 서버를 부르지 못하게 합니다. 제품에서는 Gleo Interface와 기기 인증으로 바꿉니다.

네이버·공공데이터포털·Gemini 키는 앱에 넣지 않고 중계 서버(Cloudflare Workers, `relay/`)의 비밀값에만 둡니다.

## 권한과 까닭

| 권한 | 까닭 |
|---|---|
| `pleos.car.permission.CAR_CLIMATE`·`CAR_SEATS`·`CAR_LIGHTS`·`CAR_WINDOWS`·`CAR_DOORS`·`CAR_DRIVE`·`CAR_POWERTRAIN`·`CAR_INFO` | 기어·속도·브레이크·깜빡이·창·문·자리·공조·무드등을 읽어 지금 순간과 말해도 되는 때를 고릅니다 |
| `pleos.car.permission.CAR_SAFETY` | 에어백이 터졌는지 읽어 사고 안내를 엽니다(에뮬레이터에는 이 값이 없어 시연은 버튼으로) |
| `pleos.car.permission.CONTROL_CAR_CLIMATE`·`CONTROL_CAR_LIGHTS`·`CONTROL_CAR_SEATS` | 쪽잠 깨우기의 빛·바람, 대화 중 바람 낮추기, 잘래요의 열선(제품은 앱마켓 사전 협의 대상) |
| `pleos.car.permission.NAVI_ROUTE`·`NAVI_ROUTE_SEARCH`·`NAVI_CUSTOM_MAP` | 지금 위치를 읽고 쉼터·병원을 경유지로 넣습니다 |
| `pleos.car.permission.STT_SERVICE` | [프렌드]를 누른 뒤나 PREND가 물은 뒤 몇 초의 짧은 말을 알아듣습니다(기기 안 모드) |
| `android.car.permission.CAR_SPEED`·`CAR_POWERTRAIN`·`CAR_EXTERIOR_ENVIRONMENT`·`CAR_EXTERIOR_LIGHTS`·`CAR_INFO` | 속도·기어·바깥 기온·야간 모드·유종과 주유구 위치 |
| `RECORD_AUDIO`, `FOREGROUND_SERVICE_MICROPHONE` | 대화 중엔 소리 낮추기를 켠 운행에서만 말소리가 있는지 잽니다(내용은 듣지 않음) |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SPECIAL_USE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | 운행 내내 운전 시간을 세는 서비스와 PREND 음악 |
| `RECEIVE_BOOT_COMPLETED` | 시동(부팅)과 함께 깨어납니다 |
| `POST_NOTIFICATIONS` | PREND 화면을 열지 않은 운행에서 물음을 알림 카드로 띄웁니다 |
| `INTERNET` | 중계 서버(밥집·카페, 실시간 병원, 생성형 AI 대역) |

다른 음악 앱의 곡 이름은 사용자가 알림 액세스를 켰을 때만 읽고, 알림 내용은 읽지 않습니다.

## 데이터 약속

- **마이크는 말소리 여부만.** 대화 중엔 소리 낮추기를 켠 운행에서만 열고, 기기 안의 Silero VAD로 말소리가 있는지만 판정합니다. 글자로 바꾸지 않고 저장하거나 보내지 않습니다.
- **[프렌드] 뒤 몇 초의 말**은 Pleos 음성 인식 기기 안 모드로 글자가 되어 할 일을 고르는 데만 쓰입니다. 정해 둔 말에 맞지 않을 때만 그 글자를 중계 서버를 거쳐 Gemini에 보내 할 일 하나를 고르고, 저장하지 않습니다.
- **위치**는 급할 때 병원을 찾는 요청, 차가 설 때 골목인지 볼 때(지나온 자리, TMAP 도로 등급), 초보가 P에서 목적지를 정했을 때(목적지 한 점과 근처 주차장), "화장실 급해"라고 했을 때(지금 자리와 진행 방향, TMAP 주변 주유소), 급할 때 일반 도로에서 119에 말할 위치를 만들 때(지금 자리 한 점, TMAP 도로 이름)에만 보냅니다. 밥집·카페·가까운 블루핸즈는 동네 이름만 보냅니다. 출발 전 날씨는 목적지의 5km 격자 번호와 도착 시각만 보냅니다. 처음 세워 둔 때 카드 한 장으로 알리고, [보내지 않기]나 [설정]의 [위치 보내기]를 끄면 어느 것도 보내지 않습니다(병원은 앱 안 목록, 화장실은 앱 안 주유소 자료, 골목은 차 신호로 가르고, 날씨 줄·밥집·카페·블루핸즈·골목 목적지는 쉽니다). 기록(prend.log)에는 위치와 들은 말의 글자를 남기지 않고 길이만 남깁니다.
- **차 안에 남기는 것**은 대답과 그 시각, 설정, 운전 시간, 쪽잠 길이, 내 보험사, 사고 메모(시각·119에 말할 위치 한 줄·날씨, [다 했어요]를 누를 때까지), 정비한 때(항목별 거리·날짜)와 정비소에 간 날짜·거리, 밤에 달린 운행인지(최근 30번 예·아니오)입니다.
- **달리는 동안 화면**은 멈춘 글 한 줄과 큰 버튼 두 개까지 둡니다. 설정·밥집·카페·차 정비·앱 정보·응급처치 카드는 세워 둔 동안만 열립니다.
- **응급 안내 문장**은 소방청 교육자료, 2025년 한국 심폐소생술 가이드라인, 한국도로공사, 행정안전부 안내로 미리 써 두었습니다. 생성형 AI는 문장을 짓지 않고, 정해 둔 말로 알아듣지 못한 말을 어느 안내로 보낼지 고르는 데만 씁니다.

## 시연 조건

- Pleos Connect 에뮬레이터와 Virtual Console로 기어·속도·창·문·깜빡이·와이퍼를 실제로 움직입니다(`tools/vcride.js`).
- 에뮬레이터에 없는 값은 시연 패널(PREND 화면 위 막대의 이름을 3초 안에 다섯 번, 시연 패널과 PT 시연 버튼은 디버그·PT 빌드에만)이나 시험 명령으로 넣고, 그 자리에서 밝힙니다: 에어백 대신 버튼, 시연용 바깥 기온, 연속 운전 1시간 59분 50초, 시연 값(안정 주행 판정 20초 → 5초, 깜빡이 뒤 10초 → 2초).
- 시험 명령(디버그·PT 빌드만): `adb shell am broadcast --user 10 -a app.prend.RIDE --es cmd <명령>`. 명령은 `RideService.kt`의 시험 명령 수신기에 있습니다.
- **생성형 AI 대역**: 제품에서는 Gleo AI가 맡을 자리를 시연에서는 Gemini API가 대신합니다. AI가 하는 일은 [프렌드]가 못 알아들은 말을 앱의 할 일 하나로 바꾸는 것뿐이고, 대사와 응급 안내는 사람이 미리 써 둔 것만 씁니다.
- **음악**: 시연 음악과 빗소리는 팀이 코드로 직접 합성했습니다(`tools/make_music.js`). 일반 가요에 같은 동작을 걸려면 음악 앱 연동이 필요합니다.
- **목소리**: Gemini TTS로 미리 만든 AI 합성 음성입니다(`app/src/main/assets/voice`).
