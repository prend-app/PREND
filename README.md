# PREND (프렌드)

**PREND(프렌드)는 차의 신호로 운전자에게 지금 필요한 것을 알아채고 부르기 전에 먼저 말을 거는 Pleos Connect 앱으로, 오래 달리면 쉬어 가자고 권하고 사고로 멈춰 서면 "혹시 사고 나셨어요?"라고 먼저 묻습니다.**

현대자동차그룹 차량용 앱 개발 공모전 출품작입니다. 이름은 기어 P·R·N·D 사이에 급할 때의 E(Emergency)를 넣은 것이고, 앱 화면에서는 E를 '긴급'이라고 씁니다. 주로 생각한 사용자는 첫 차를 모는 초보와 아이를 태우는 부모입니다. 급한 순간에는 누구나 당황하니 다른 운전자에게도 그대로 쓰입니다.

## 한눈에 보기

- **평소:** 두 시간 넘게 달리면 쉬어 가자고 먼저 권합니다. 깜빡이를 켰거나 후진하는 중, 급제동 직후처럼 바쁜 순간에는 하려던 말을 미룹니다.
- **급할 때:** 접촉 사고로 보이면 "혹시 사고 나셨어요?"라고 먼저 묻고, 할 일을 한 문장씩 말하고, 119에 말할 위치를 화면에 띄웁니다.
- **한마디로:** [프렌드] 단추를 누르고 "애가 멀미해", "경고등 켜졌어"처럼 말하면 그 일을 합니다.
- **가장 빨리 보는 법:** 설치하고 PREND를 연 뒤 첫 화면의 [긴급]을 누릅니다. 가상 차를 움직이지 않아도 됩니다(아래 '실행 방법' 3).
- **시연 영상:** https://youtu.be/dPmPsczB4y4 (4분 19초. 에뮬레이터의 화면과 소리를 그대로 녹화했습니다)
- **시험한 곳:** Pleos Connect 에뮬레이터 v2.1.0입니다. 실제 차에서는 시험하지 않았습니다.
- **에뮬레이터에 없어 대신 넣은 값:** 에어백 신호, 고속도로 위 위치, 블루링크 통화입니다(아래 '실제 신호와 대신 넣은 값').

## 실행 방법

### 1. 설치

Pleos Connect 에뮬레이터(Android Automotive 14, x86_64)를 켜고 둘 가운데 하나를 깝니다.

```
adb install -r --user 10 "apk/김민규_PREND_pt.apk"        # PT판: 아래 5번의 시연 패널까지 보려면 이 파일
adb install -r --user 10 "apk/김민규_PREND_release.apk"   # 출시판: 제출한 그대로(시연 패널 없음)
```

- PT판은 출시판에 시연 패널과 시험 명령을 더한 것입니다(PT는 본선 발표). 그 밖의 동작은 출시판과 같습니다.
- 두 파일은 같은 키로 서명해, 지우지 않고 서로 바꿔 깔 수 있습니다.
- `--user 10`은 에뮬레이터에서 화면을 쓰는 사용자 번호입니다.

### 2. 처음 열기

1. 런처에서 PREND를 엽니다.
2. 안내 한 장을 넘기면 차 속도와 알림 권한을 묻습니다. [허락하기]를 누릅니다. 거절해도 첫 화면에 [허락하기]가 남아 나중에 누를 수 있습니다.
3. 처음 세워 둔 채 문이 모두 닫히면 카드 두 장이 차례로 뜹니다. 함께 타는 아이가 있는지 묻는 카드와, 위치를 어디에 쓰는지 알리는 카드입니다.

사고 물음, 두 시간 쉼터 권하기, 바쁜 순간에 말 미루기, 급할 때 안내는 처음부터 켜져 있습니다. 덜 급한 물음 여섯 가지(한 시간 운전, 대리 운행, '대화 중엔 소리 낮추기', 오래 막힐 때, 밥집, 카페)는 꺼 둔 채로 시작하고 [설정]의 '먼저 물어볼 것'에서 켭니다. 마이크 권한은 '대화 중엔 소리 낮추기'(차 안에서 말소리가 들리면 음악과 바람 소리를 낮추는 설정)를 켤 때에만 묻습니다.

### 3. 가상 차를 움직이지 않고 보기: [긴급]

첫 화면의 큰 단추 [긴급]을 누릅니다(달리는 동안에는 화면 가운데의 [긴급] 줄). [사고가 났어요], [갑자기 아파요], [고장 났어요], [연기가 나요] 가운데 하나를 고르면 그 상황의 할 일이 화면과 목소리로 한 걸음씩 나옵니다.

### 4. 가상 차를 움직여 사고 물음 보기

터미널에서 `adb forward tcp:8088 tcp:8088`을 친 뒤 브라우저로 http://127.0.0.1:8088 을 열면 에뮬레이터의 가상 차 조작 화면(Virtual Console)이 나옵니다. 기어와 페달은 첫 화면에, 문과 깜빡이는 두 번째 탭(Emulation Controls)에 있습니다.

**급제동으로 멈춘 경우**

1. 기어 D를 누르고 가속 페달로 시속 60쯤까지 올립니다.
2. 브레이크를 3초 동안 밟습니다. 속도가 1초에 시속 15km 넘게 줄어야 급제동으로 봅니다.
3. 급제동을 시작하고 5초 안에 차가 멈춰야 합니다.
4. 멈춘 뒤 1분 안에 기어 P를 누릅니다.
5. Emulation Controls의 Door Position에서 Front left(운전석 문)를 Open합니다.
6. PREND가 목소리와 카드로 "혹시 사고 나셨어요?"라고 묻습니다. [사고가 났어요]를 누르면 사고 안내가 시작되고, [아니에요]를 누르면 닫힙니다.

**접촉 사고의 충격을 받은 경우**

1. 기어 D를 누릅니다. 서 있어도, 달리던 중이어도 됩니다.
2. 터미널에서 충격을 넣습니다(옆으로 1g 넘게 튄 충격). 첫 줄을 치고 1초쯤 뒤에 둘째 줄을 칩니다.
   ```
   adb emu sensor set acceleration-uncalibrated 15:9.78:0.81
   adb emu sensor set acceleration-uncalibrated 0:9.78:0.81
   ```
3. 달리던 중이면 10초 안에 멈춥니다. 그 뒤 1분 안에 기어 P → 운전석 문 Open → "혹시 사고 나셨어요?"

알아 둘 것:

- 앱은 기기의 가속도 센서로 충격을 읽습니다(`car/Jolt.kt`).
- 충격만으로도, 급제동만으로도 묻지 않습니다. 멈춤, 기어 P, 운전석 문이 이어져야 묻습니다.
- 가속도 센서가 없는 차에서는 급제동으로만 살핍니다.
- 충격으로 보는 크기(옆으로 1g)는 실제 차로 맞춘 값이 아닙니다.

**도구로 한 번에 하기.** `tools` 폴더에서 `npm install`을 한 번 한 뒤:

```
node vcride.js D gas:4000 brake:3000 wait:1500 P wait:800 "door:Front left:Open"   # 급제동
node vcride.js D wait:2500 jolt:1.5 wait:1500 P wait:800 "door:Front left:Open"    # 서 있다 받은 충격
```

### 5. 에뮬레이터에 없는 값 넣기: 시연 패널 (PT판)

PREND 화면 맨 위 막대의 이름(P R E N D)을 3초 안에 다섯 번 누르면 시연 패널이 열립니다. `apk/` 폴더에서는 PT판에만 있습니다. 아래 다섯 장면 단추가 패널 맨 아래에 있습니다.

| 단추 | 넣는 값 | 누른 뒤 할 일 | 보이는 것 |
|---|---|---|---|
| ① 장면 준비 | 새 운행, 기준 값 | 없음 | 첫 화면 |
| ② 고속도로 | 고속도로 위 위치 | 위 4번의 급제동 걸음 그대로 | 대피 문장("차 뒤로 가지 말고 가드레일 밖으로 나가세요")을 먼저 말한 뒤 "혹시 사고 나셨어요?". [사고가 났어요]를 누르면 비상등 → 가드레일 밖 → 119에 말할 위치("○○고속도로 ○○ 방향 ○km 지점") |
| ③ 블루링크 통화 + 에어백 | 에어백 신호, 상담원 통화(8초) | 없음 | 사고 안내가 열리고, 통화 동안에는 말하지 않고 기다렸다가 통화가 끝나면 "괜찮으세요?"부터 이어 갑니다 |
| ④ 말 삼키기 | 연속 운전 1시간 59분 50초 | 기어 D → 가속 → 깜빡이(Turn Signal State) Blink left → 10초쯤 뒤 Off | 깜빡이를 켠 동안 미뤘던 "두 시간 넘게 달리셨어요. 앞쪽 쉼터에서 쉬어 가실래요?"를 끈 뒤에 건넵니다 |
| ⑤ 화장실 | 수원 시내 도로 위치 | 기어 D → 가속 → [프렌드] → "애가 쉬 마렵대"(아래 6번) | 앞쪽에서 들르기 쉬운 주유소 한 곳을 카드로 묻고, [경유지로]를 누르면 내비에 넣습니다 |

- ②~⑤는 ①(장면 준비)부터 스스로 하고 시작하므로 단추 하나만 누르면 됩니다.
- 조작 화면에서 문이 열려 있으면 패널 맨 위에 크게 알립니다. 문을 닫고 시작합니다.
- [시험 값 모두 끔]은 넣은 값을 지우고, [시연 값 끔]은 시연용으로 줄여 둔 기다리는 시간을 원래대로 돌립니다.

### 6. 말로 하는 장면: [프렌드]

[프렌드]는 말하기 단추입니다(세워 둔 첫 화면의 큰 단추, 달리는 동안에는 오른쪽 위). 누른 뒤 몇 초 동안 듣습니다. 에뮬레이터에 PC 마이크가 연결되어 있으면 그대로 말하고, 아니면 듣는 동안 시험 명령으로 말을 넣습니다(PT판, 빈칸 없이 적습니다).

```
adb shell am broadcast --user 10 -a app.prend.RIDE --es cmd heard_애가멀미해
```

| 말 | 하는 일 |
|---|---|
| "애가 멀미해" | 공조를 바깥 공기로 바꾸고 바람을 얼굴 쪽으로 돌립니다 |
| "애가 쉬 마렵대", "화장실 급해" | 앞쪽에서 들르기 쉬운 휴게소·졸음쉼터·주유소 한 곳을 카드로 묻습니다 |
| "경고등 켜졌어" (세워 둔 동안) | 경고등 목록을 띄우고, 고른 경고등의 뜻과 할 일을 보여 줍니다 |
| "아이가 열이 나" | "숨쉬기나 의식이 이상하면 119가 먼저예요"라고 말한 뒤 지금 여는 달빛어린이병원(밤·휴일 소아 진료)과 응급실을 보여 줍니다 |

**대피 안내 뒤.** 사고·고장 안내에서 차 밖으로 피하라는 말이 나온 다음, 조작 화면에서 아무 문이나 Open하면 내린 것으로 보고 목소리를 멈춥니다. 자리에 앉은 채 문을 Close하면 안내를 이어 갑니다.

## 테스트 환경 (에뮬레이터 버전과 화면 규격)

- **에뮬레이터:** Pleos Connect 에뮬레이터 v2.1.0(AVD 이름 `Pleos_Connect_v2_1`, Android Automotive 14, x86_64)와 Virtual Console, Windows 11. 실제 차에서는 시험하지 않았습니다(공모전 검증은 에뮬레이터).
- **화면 규격:** 에뮬레이터 화면 2560×1440px, 160dpi(1dp = 1px). PREND는 그 가운데 오른쪽 앱 영역 1680×1210dp에 맞춰 그렸습니다(왼쪽은 계기판, 위아래는 상태 막대와 단추 줄).
- **인터넷:** 실시간 병원 찾기, 밥집·카페, 정해 둔 말에 없는 말을 알아듣는 생성형 AI는 중계 서버를 거칩니다. 중계 서버는 외부 API 키를 대신 들고 있는 Cloudflare Workers이고 소스는 `relay/`에 있습니다. 인터넷이 없어도 급할 때 안내와 앱 안 병원 목록은 그대로 됩니다.
- **설정:** 따로 맞출 것은 없습니다. 권한은 매니페스트의 Pleos SDK 권한 선언으로 충분하고(공모전 개발 단계는 승인 불필요), 실행 중에 묻는 것은 차 속도와 알림 두 가지입니다.

## APK 위치

- `apk/김민규_PREND_release.apk`: 출시판. 에뮬레이터용(x86_64)과 실제 차용(arm64-v8a) 파일을 함께 담았습니다. 시험은 에뮬레이터에서만 했습니다. 출시 키로 서명했습니다.
- `apk/김민규_PREND_pt.apk`: PT판. 출시판에 시연 패널과 시험 명령을 더한 것입니다(`gradlew assemblePt`). 출시판과 같은 키로 서명했습니다.

두 파일에는 시연용 중계 서버 토큰이 들어 있어 실시간 병원 찾기, 밥집·카페, 생성형 AI가 그대로 됩니다.

## 실제 신호와 대신 넣은 값

가상 차 조작 화면으로 기어, 속도, 문, 창, 깜빡이, 와이퍼는 실제로 움직입니다(`tools/vcride.js`). 에뮬레이터에 없는 값만 시연 패널이나 시험 명령으로 넣고, 넣은 동안에는 PREND 화면 위 막대에 '시연' 표시가 뜹니다.

| 실제 차에서는 | 에뮬레이터 시연에서는 |
|---|---|
| 에어백이 터졌다는 신호 | 시연 패널의 단추(③) |
| 고속도로 위 위치, 블루링크 상담원 통화 | 시연 패널의 단추(②, ③) |
| 접촉 사고의 충격 | 에뮬레이터의 가속도 센서에 넣은 값 |
| 두 시간 연속 운전 | 1시간 59분 50초에서 시작(10초 뒤에 권함) |
| 바깥 기온 | 시연용 값 |
| 기다리는 시간(안정 주행 판정 20초, 깜빡이를 끈 뒤 10초) | 시연용으로 5초, 2초 |

- **생성형 AI:** 제품에서는 Gleo AI가 맡을 자리를 지금은 Gemini API가 대신합니다. AI가 하는 일은 [프렌드]가 못 알아들은 말을 앱의 기능 하나로 바꾸는 것뿐입니다. 대사와 응급 안내는 사람이 미리 써 둔 것만 씁니다.
- **목소리:** Gemini TTS로 미리 만든 AI 합성 음성입니다(`app/src/main/assets/voice`).
- **음악:** 시연 음악과 빗소리는 코드로 직접 합성했습니다(`tools/make_music.js`). 다른 음악 앱의 곡에 같은 동작을 걸려면 그 앱과의 연동이 필요합니다.
- **시험 명령(PT판·디버그판):** `adb shell am broadcast --user 10 -a app.prend.RIDE --es cmd <명령>`. 장면 단추와 같은 명령은 `pt_e_ready`(①), `pt_highway`(②), `pt_bluelink`(③), `pt_swallow`(④), `pt_toilet`(⑤), `pt_clean`(시험 값 모두 끔), `pt_values_off`(시연 값 끔)이고, 나머지는 `RideService.kt`에 있습니다.

## 기능

시동과 함께 깨어나 운행 내내 켜져 있는 서비스(`RideService.kt`)가 차 신호를 받아 지금이 어느 순간인지 고르고, 목소리·카드·공조·경유지로 챙깁니다. 아래에서 '운전 도움'은 초보 운전자가 켜 두는 설정입니다.

### E 급할 때

| 상황 | PREND가 하는 일 |
|---|---|
| 접촉 사고로 보일 때 | 충격 또는 급제동 → 멈춤 → 기어 P → 운전석 문 열림이 이어지면 "혹시 사고 나셨어요?"라고 묻습니다. 급제동만으로는 묻지 않습니다 |
| 사고 | 고속도로, 일반 도로, 가벼운 사고에 맞춘 순서를 한 문장씩 말합니다 |
| 고장 | 고속도로와 일반 도로에 맞춘 순서, 고속도로 무료 긴급견인 1588-2504, 부르지 않은 견인차가 왔을 때의 대처 |
| 고속도로 위에서 기어 P | "고속도로 위에 서셨어요"라고 먼저 말을 걸고 대피 카드를 띄웁니다 |
| 연기·타는 냄새 | 차에서 내리는 순서를 안내합니다 |
| 갑자기 아플 때 | 운전자가 아프면 병원으로 몰고 가지 말고 세운 뒤 119. 같이 탄 사람이 아프면 병원을 경유지로 |
| 어느 상황에서나 | 119에 말할 위치를 화면에 띄우고, 응급처치 카드(심폐소생술, 목에 걸렸을 때, 경련)와 119 전화 단추를 둡니다 |

### N·D 달리는 중

- **말해도 되는 때 고르기:** 깜빡이, 후진, 급제동, 회전 직전, 내비가 길을 다시 찾는 중에는 말하지 않고 미룹니다. 카드는 차가 설 때만 띄웁니다.
- **두 시간 달리면 쉼터 권하기:** 앞쪽 졸음쉼터와 휴게소를 권하고, 주유소가 있으면 표시합니다.
- **화장실:** "화장실 급해", "애가 쉬 마렵대"라고 하면 앞쪽 휴게소·졸음쉼터(수유실 표시)나 오른쪽 앞 주유소를 카드로 권하고, "응"이면 경유지로 넣습니다.
- **멀미:** "애가 멀미해"라고 하면 바깥 공기로 바꾸고 바람을 얼굴 쪽으로 돌립니다.
- **'잘래요':** 같이 탄 사람이 잘 때 누르면 음악을 낮추고 먼저 말을 걸지 않습니다.
- **김 서림:** 비가 오거나 추운 날 안쪽 공기만 10분 넘게 돌면 바깥 공기로 바꿀지 한 번 묻습니다. "앞유리에 김 서렸어"라고 하면 앞유리 성에 제거를 켭니다.
- **'운전 도움'을 켠 사람에게 한마디:** 비 오는 날은 그 길 제한속도에 맞춰 "시속 60 아래"처럼, 회전교차로, 우회전. 끈 사람에게는 젖은 길과 우회전만 소리 없는 카드로 한 번 띄웁니다.
- **음악:** 창문을 열거나 차 안에서 이야기를 나누면 PREND가 트는 음악을 낮춥니다.
- **화면:** 달리는 동안에는 움직이지 않는 글 한 줄과 큰 단추 두 개까지만 둡니다. 설정, 밥집·카페, 차 정비, 앱 정보, 응급처치 카드는 세워 둔 동안만 열립니다.

말을 아끼는 규칙:

| 규칙 | 내용 |
|---|---|
| 먼저 꺼내는 횟수 | PREND가 먼저 꺼내는 말과 카드는 한 운행에 많아야 여섯 번 |
| 동승자가 있을 때 | 대리 운행, 정체, 주차 자리처럼 민망할 수 있는 말은 소리 없는 카드로. 쉼터와 급할 때는 목소리로 |
| '급한 말만 하기' | 켜면 쉼터와 급할 때 말고는 카드로만 알립니다. 이번 운행만 켜거나 늘 켜 둘 수 있습니다 |

### P·R 세워 두거나 주차하는 동안

- **주차:** 낮인데 어두운 곳(지하·실내 주차장)에 세우면 내리기 전에 주차 자리를 확인하라고 한 번 알립니다. 주차하는 동안에는 조용히 있습니다(차의 주차 경고음이 들리게). "주차 도와줘"라고 하거나 '운전 도움'을 켠 채 전진과 후진을 여러 번 오가면, 멈춰 서서 핸들을 돌릴 때 바퀴가 어느 쪽으로 꺾였는지 말해 줍니다.
- **출발 전:** 해가 진 뒤에 도착할 길이면 "도착하면 어두워요", 목적지의 비·눈 예보, '운전 도움'을 켰으면 골목 안 목적지에 큰길가 주차장을 한 번 권합니다.
- **차 정비:** 항목마다 정비할 때, 직접 할 수 있는 것, 가까운 블루핸즈, 정비소에서의 권리를 보여 줍니다. 정비소에 가면 오늘 날짜로 [기록하기].
- **경고등이 켜졌을 때:** "경고등 켜졌어"라고 하거나 차 정비 화면에서 열어 계기판과 같은 모양을 고르면, 열 가지 경고등의 뜻과 할 일을 현대차 취급설명서대로 보여 줍니다. 어떤 경고등이 켜졌는지는 일반 앱이 읽지 못해 운전자가 고릅니다.
- **그 밖에:** 쪽잠과 깨우기, 밥집·카페, 설정.

### 말하기·듣기

- "뭐라고?"라고 하면 방금 한 말을 천천히 다시 말합니다. 자주 되물으면 늘 천천히 말합니다.
- 대답이 늦으면 듣는 시간을 늘립니다(나이를 묻지 않고 쓰는 모습에 맞춥니다).
- 대답을 못 알아들으면 한 번만 다시 묻고, 그다음에는 카드의 단추만 둡니다. 아이가 타는지 묻는 카드와 동승자가 있을 때는 처음부터 카드만 둡니다.
- 사투리 대답(하모·그려·아이다·뭐라카노)도 알아듣습니다.
- '천천히 말하기'와 '대답 넉넉히 기다리기'는 [설정]에서 직접 켜고 끌 수도 있습니다.

## 빌드

필요한 것: JDK 17, Android SDK 35(`local.properties`의 `sdk.dir`이나 `ANDROID_HOME`). Gradle 8.13은 들어 있는 `gradlew`가 받습니다(AGP 8.8.2, Kotlin 2.2.21). Pleos Playground SDK는 `settings.gradle.kts`의 Pleos Maven 저장소에서 받습니다.

```
gradlew assembleDebug     # 디버그판: 시연 패널과 시험 명령
gradlew assembleRelease   # 출시판: R8로 줄임, 시연 패널 없음
gradlew assemblePt        # PT판: 출시판과 같은 최적화 + 시연 패널과 시험 명령
```

PowerShell에서는 `.\gradlew`, macOS·Linux에서는 `./gradlew`로 부릅니다.

- 세 가지 모두 에뮬레이터용(x86_64)과 실제 차용(arm64-v8a) 파일을 함께 담습니다. 심사를 에뮬레이터에서 하므로 출시판에도 에뮬레이터용을 넣었습니다.
- 출시 키는 저장소 바깥(`../.secrets/keystore.properties`와 키 파일)에 두고, 없으면 디버그 키로 서명합니다. PT판도 같은 출시 키로 서명합니다. 디버그판은 디버그 키라 출시판·PT판과 바꿔 깔 때는 먼저 `adb uninstall app.prend`로 지웁니다.
- minSdk 28, targetSdk 35.

### 키는 저장소에 없습니다

앱이 쓰는 비밀값은 중계 서버를 부르는 앱 토큰 하나입니다. `app/build.gradle.kts`가 빌드할 때 저장소 바깥의 `../.secrets/relay-token.txt`를 읽어 `BuildConfig.RELAY_TOKEN`에 넣습니다. 이 저장소에서 직접 빌드하면 그 파일이 없어 빈 값으로 빌드되고, 중계 서버를 거치는 기능(밥집·카페, 실시간 병원 찾기, 생성형 AI)만 꺼집니다. 나머지는 그대로 돌고, 병원은 앱에 넣어 둔 목록에서 고릅니다. `apk/`의 두 파일에는 토큰이 들어 있습니다.

이 토큰은 공모전 시연용입니다. 중계 서버는 보낸 곳(IP)마다 1분에 40번, 생성형 AI는 1분에 10번까지만 받고, 생성형 AI는 모든 곳을 합쳐 하루 500번에서 멈춥니다(`relay/wrangler.jsonc`, `relay/src/worker.js`). 멈춘 동안 앱은 "서버가 바빠요"라고 알리고, 정해 둔 말과 급할 때 안내는 그대로 됩니다. 공모전이 끝나면 토큰을 바꿔 지난 APK가 서버를 부르지 못하게 합니다. 제품에서는 Gleo Interface와 기기 인증으로 바꿉니다.

네이버·공공데이터포털·Gemini 키는 앱에 넣지 않고 중계 서버(Cloudflare Workers, `relay/`)의 비밀값에만 둡니다.

## 개인정보와 데이터

- **마이크는 말소리가 있는지만 잽니다.** '대화 중엔 소리 낮추기'를 켠 운행에서만 열고, 기기 안의 Silero VAD로 말소리가 있는지만 판정합니다. 글자로 바꾸지 않고, 저장하거나 보내지 않습니다.
- **[프렌드] 뒤 몇 초의 말**은 Pleos 음성 인식의 기기 안 모드로 글자가 되어 기능을 고르는 데만 쓰입니다. 정해 둔 말에 맞지 않을 때만 그 글자를 중계 서버를 거쳐 Gemini에 보내 기능 하나를 고릅니다. 앱과 중계 서버는 그 글자를 저장하지 않습니다.
- **응급 안내 문장**은 소방청 교육자료, 2025년 한국 심폐소생술 가이드라인, 한국도로공사, 행정안전부 안내로 미리 써 두었습니다. 생성형 AI는 문장을 짓지 않습니다.
- **기록 파일(prend.log)**에는 위치와 들은 말의 글자를 남기지 않고 길이만 남깁니다.
